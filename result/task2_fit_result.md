# 任务 2：合成旋转视频参数拟合

## 1. 模型

目标角速度遵循：

```
ω(t) = b + A·sin(Ωt + φ)
```

| 参数 | 含义 | 单位 |
|---|---|---|
| A | 振幅 | rad/s |
| b | 平均角速度 | rad/s |
| Ω | 频率参数（速度变化周期 T = 2π/Ω） | rad/s |
| φ | 相位（报告到 [−π, π)） | rad |

时间以秒为单位，角度以弧度为单位，所有参数以视频第 0 帧为时间原点。

## 2. 方法

1. **目标检测**：对 `task_2.mp4`（960×720，60 FPS，共 1440 帧）逐帧做 HSV 青色阈值分割
   （H ∈ [80, 100]），取最大连通块的质心作为目标中心 `(x_i, y_i)`。
   检测结果：**1440 / 1440 帧全部有效**。
2. **角度计算**：`θ_i = atan2(c_y − y_i, x_i − c_x)`，其中旋转中心 `(c_x, c_y) = (480, 360)`；
   再对 `θ` 做解缠（unwrap），消除跨 ±π 的跳变，得到连续递增序列。
3. **角速度**：中心差分 `ω_i = (θ_{i+1} − θ_{i−1}) / (2·dt)`，`dt = 1/60 s`，
   首尾两帧用单侧差分（保证 ω 与 θ 等长、时间轴对齐）。
4. **参数拟合（Ω 网格搜索 + 线性最小二乘）**：利用三角恒等式

   ```
   ω = b + A·sin(Ωt + φ) = b + (A·cosφ)·sin(Ωt) + (A·sinφ)·cos(Ωt)
   ```

   固定 Ω 后，模型对 `[b, A·cosφ, A·sinφ]` 是线性的。因此对 Ω 做**一维网格搜索**
   （粗扫 0.05~8.0 rad/s、步长 0.01，再精扫最优值 ±0.01、步长 0.001），
   每个 Ω 用 Eigen 的 `colPivHouseholderQr().solve()` 解 3×3 线性最小二乘，取残差平方和（SSE）最小者。

## 3. 参数估计结果

| 参数 | 估计值 | 单位 |
|---|---|---|
| A（振幅） | 0.550 | rad/s |
| b（平均角速度） | 1.350 | rad/s |
| Ω（频率参数） | 1.65 | rad/s |
| φ（相位） | 0.701 | rad |

**约束验证**：`A > 0` ✓；`b > A`（1.350 > 0.550）✓；`Ω > 0` ✓；`φ ∈ [−π, π)` ✓。

## 4. 误差指标

- 拟合量：角速度 ω
- 误差类型：**角速度误差**
- **RMSE = 0.0311 rad/s**
- 有效样本数：**1440**
- 参与计算的帧范围：**第 0 帧 ~ 第 1439 帧**
