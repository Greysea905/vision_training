# 任务 3：真实能量机关识别与稳定跟踪

## 1. 检测方法

- **模型**：YOLOv11n（约 2.6M 参数），在自建数据集上训练。
  - 数据集：`task_3.mp4`（小机关）+ `task_4.mp4`（大机关）共 866 帧，2 类：`0=R标`、`1=目标靶`。
  - 训练：AutoDL GPU（RTX PRO 6000），100 epoch，`imgsz=1280`。验证集 mAP50=0.99、mAP50-95=0.934。
- **推理**：C++ + OpenCV `cv::dnn::readNetFromONNX`（零额外依赖，CPU 离线处理）。
  - 预处理：letterbox 等比缩放 + 居中补边到 1280×1280，`/255` 归一化，BGR→RGB（与训练端一致）。
  - 后处理：输出张量 `[1, 6, 33600]`（4 坐标 + 2 类置信度）解析 → 置信度过滤（0.5）→ 按类别 NMS（IoU 0.45）→ 反 letterbox 映射回原图坐标。
- **几何**：R标中心 = class0 框中心；扇叶圆中心 = class1 框中心；扇叶圆半径 = 框宽/2。

## 2. 锁定与重选规则（稳定锁定）

- 目标状态至少区分 **`detected`**（有效观测）与 **`lost`**（丢失）。
- **首次出现有效目标**：任选一个（取第一个检测到的 target），分配自增 ID。
- **身份保持（角速度预测 + 最近邻）**：目标绕 R标 匀速转动，逐帧估计其**角速度 ω**（EMA 平滑），预测目标当前应在的角度位置，与本帧 target 检测计算欧氏距离，取最近且 < 60px 的作为同一目标。因此**检测列表顺序变化、另一目标出现、或短暂遮挡后目标转回**，都不会改变身份（满足「不直接用轮廓列表顺序作 ID」）。
- **丢失与重选**：
  - 关联失败（最近距离 ≥ 60px）→ 状态置 `lost`，`lost_count++`，但**保留身份**。
  - lost 期间沿预测圆周**外推**目标位置，圆平滑继续转动（不冻结、不乱跳）。
  - 短暂遮挡后目标在预测位置附近重现 → 认回同一目标，恢复 `detected`，**ID 不变**。
  - `lost_count > 15`（丢失容忍帧数）→ 判定为**熄灭**，释放该目标；下一帧重新选择时分配**新 ID**。
- **角度**：逐帧用「目标中心 − R标中心」计算 `atan2` 角度，使用每帧检测到的**移动中心**，不用固定图像坐标。

## 3. 可能的失败情况

- **R标漏检**：R标仅 ~20px，在极端光照或快速运动时可能漏检，导致该帧中心缺失（不影响 target 跟踪，仅影响连线/角度）。
- **关联串台**：两靶距离 < 60px 时最近邻可能误配（本场景靶位于不同扇叶、相距数百像素，实际未发生）。
- **剧烈运动误判丢失**：相机快速运动导致帧间位移 > 60px 时可能误判为丢失（可调大 `ASSOC_THRESH` 缓解）。

## 6. 跟踪迭代调整记录

1. **初版（冻结位置）**：目标丢失时把圆冻结在最后检测位置。问题：目标持续转动，冻结位置立刻过时 → 黄圈乱晃、遮挡后因匹配失败而跳变到另一目标、无法区分「熄灭」与「遮挡」。
2. **二版（角速度预测）**：估计目标绕 R标 的角速度 ω（EMA 平滑），匹配与丢失外推都用**预测位置**。解决乱晃与跳变，并自然区分：转回且离预测位置近 = 同一目标（ID 不变）；一直不回来 = 熄灭（释放后新 ID）。
3. **三版（预测-检测融合）**：把「旧位置 + 新检测」的 EMA 低通，改为「预测位置 + 检测位置」的卡尔曼式融合，并平滑轨道半径与框半径。同时改善残留的**抖动**与**延迟**（低通滤波的平滑与滞后本是绑定的，融合法解耦了二者）。
